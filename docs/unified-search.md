# 搜索与 AI 融合 · 统一入口

搜索片库和问 AI 是同一个入口：窗口正中的助手浮层（`features/assistant`）。侧栏的搜索框（其实是按钮）、
收起侧栏时的放大镜、`⌘K / Ctrl+K`、`⌘⇧K / Ctrl+Shift+K`（原助手快捷键）与系统级快捷键都打开它；
`⌘F / Ctrl+F` 只打开（焦点在别的对话框里时不抢）。没有第二套搜索面板。

- 输入框一有字就即时搜，一份结果列表：结果块接在输入胶囊下面（空闲态）或面板里输入框上方（对话态）。
  从上到下：「问 AI：<输入>」一行（对话，单独一行）→ 本地片库（海报行：本地各路召回与 AI 增强融合去重，
  画面时刻、人物）→ 在线影视源（异步追加，同名同年多个源合成一行，最多 12 行）。
- 范围胶囊：全部（默认，本地 + 在线）/ 本地 / 在线；在电影页、剧集页多一枚「电影」/「剧集」只搜当前分区。
  私密模式没有胶囊：只搜本地私密库，不搜在线、不做 AI 增强。网页版没有在线源，也没有「在线」胶囊。
- 本地结果先出（停 120ms）；在线源停 450ms 再搜、各源返回就追加；继续打字作废旧的一轮，都不阻塞输入。
- `↑ ↓` 选择，回车作用在选中行；默认选中：片名精确命中 → 那部片，否则「问 AI」行（网页版没有这一行，选第一条结果）。
  `⌘↵ / Ctrl+↵` 与发送钮总是问 AI。Tab 仍按焦点陷阱在浮层控件间移动。
- AI 未配置时搜索照常可用，「问 AI」行写明需要先配置，问了会在对话里给出「去设置 AI」。

## 查询与结果

- 输入停顿 120ms 后发起本地查询；输入变化、停止或关闭立即作废旧查询，迟到结果不更新界面。
- 片名沿用引擎 FTS 的片名、原名、简繁与大小写匹配。没有增加拼音索引或额外别名数据。
- 人物通过已有演职员查询召回作品；番号范围额外展示现有演员库的匹配人物。
- 条件只用规则解析明确的年代、评分、类型与地区，交接到海报墙后在那里编辑、切换和删除。
- CLIP 保留本地封面、剧照与关键帧搜索。现有引擎索引范围为番号库，普通片库不读取该索引。
  番号工具栏的“按画面搜”与统一入口（私密范围）都可选择“全部 / 仅图片 / 仅视频（抽帧）”，范围在相似度排序与 limit 截取前生效。
  使用现有已就绪的模型和索引，不因打开面板而下载模型或建立索引。缺失时提示到片库的“按画面搜”配置。
- 全局范围仅查询已解锁板块，锁状态变化时取消并清理旧结果。
- CLIP 请求串行执行，在途原生推理安全完成，过期排队请求不启动；图片 / 视频切换防抖，关闭时清除待执行查询。
- 各路并行发布结果，加权 RRF 融合，精确片名优先。单路失败只提示降级，不清空其他命中。
- 使用引擎的 `mergeKey` 合并不同召回里同作品的代表条目；手动拆分的条目保持独立。
  旧片库服务未返回此可选字段时，仅按条目 id 去重。画面命中通过一次批量查询取回各实际版本。
- 最佳匹配打开详情，画面时刻使用命中条目的实际文件与时间点播放；多版本选择沿用详情页。
- 指定分区后，可通过“在海报墙查看”交接当前条件；URL 条件经过白名单清洗，海报墙不重复调用 AI。
  海报墙上方的条件条显示「搜索「…」」胶囊，× 清除搜索词与交接条件（原来由侧栏输入框的清空按钮负责）。
- 在线结果复用在线搜索页的同一套（已启用的 CMS 与插件源）；点在线行跳到在线页打开详情，「在线搜索页」看完整结果。

## AI 与隐私

AI 增强不再是开关：AI 已配置、这句话像自然语言（`looksNatural`）、不是私密范围时，本地结果出来后再停 450ms，
把这句话交给模型解析成片库条件（`ai-conditions.ts`），按条件召回一路 `ai` 候选，与片名 / 人物 / 规则条件 / 画面
各路一起加权 RRF 融合、按作品去重，理由写「AI 理解 · 科幻 · …」。片名式输入、AI 未配置、失败或停止时只有本地结果。
云端仅接收当前查询（最多 500 字符）和固定的条件字段说明，不发送片库、字幕、文件路径或观看记录；
同一句话按服务商 / 模型 / 地址 / 年份缓存。

「问 AI」是对话，走助手的技能与隐私规则（私密模式只用本地模型、无痕；切换私密上下文时浮层收起并清空对话）。
CLIP 的描述与图片在本机处理。

## 验证与后续

回归覆盖意图权重、规则条件、精确片名、版本去重与手动拆分、来源隔离、就绪 / 缺失 CLIP、时间点播放、
取消与迟到响应、输入法回车、默认选中与回车 / Cmd+回车、焦点与快捷键。测试使用模拟模型 / bridge，不能替代真实媒体库和模型验收。

本阶段未新增字幕全文索引、简介向量模型、AI 精排、云端识图、库外追更 / 转存或助手结果追问。
助手找片技能的服务统一属于后续阶段。现有助手与片库内自然语言入口仍可使用。

性能目标是热库片名 / 人物查询 P95 ≤ 50ms，需要用真实媒体库实测；120ms 输入防抖单独计入端到端首屏耗时。
尚无真实 200 条查询评测集，本阶段不宣称达到命中率或耗时目标。

## 界面

顶部保留手机菜单、窗口控制与拖拽区域；页面内部返回入口可用。
全局隐藏滚动条，保留滚轮、触控板与键盘滚动。“今晚看什么”的片库面板和助手动作均不提供。
