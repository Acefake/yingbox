# 搜索与 AI 融合 · S1

侧栏搜索框、收起侧栏的搜索图标与 `⌘K / Ctrl+K` 打开同一个搜索面板；`⌘F / Ctrl+F` 也可使用。
助手的应用内快捷键是 `⌘⇧K / Ctrl+Shift+K`，侧栏助手入口和系统级快捷键保持可用。

## 查询与结果

- 输入停顿 120ms 后发起本地查询；输入变化、停止或关闭立即作废旧查询，迟到结果不更新界面。
- 片名沿用引擎 FTS 的片名、原名、简繁与大小写匹配。没有增加拼音索引或额外别名数据。
- 人物通过已有演职员查询召回作品；番号范围额外展示现有演员库的匹配人物。
- 条件先用规则解析明确的年代、评分、类型与地区；胶囊复用片库的编辑、切换和删除规则。
- CLIP 保留本地封面、剧照与关键帧搜索。现有引擎索引范围为番号库，普通片库不读取该索引。
  两个搜索入口均可选择“全部 / 仅图片 / 仅视频（抽帧）”，范围在相似度排序与 limit 截取前生效。
  使用现有已就绪的模型和索引，不因打开面板而下载模型或建立索引。缺失时提示到片库的“按画面搜”配置。
- 全局范围仅查询已解锁板块，锁状态变化时取消并清理旧结果。
- 各路并行发布结果，加权 RRF 融合，精确片名优先。单路失败只提示降级，不清空其他命中。
- 使用引擎的 `mergeKey` 合并不同召回里同作品的代表条目；手动拆分的条目保持独立。
  旧片库服务未返回此可选字段时，仅按条目 id 去重。
- 最佳匹配打开详情，画面时刻使用命中条目的实际文件与时间点播放；多版本选择沿用详情页。
- 指定分区后，可通过“在海报墙查看”交接当前条件；URL 条件经过白名单清洗，海报墙不重复调用 AI。
- 在线资源搜索由用户主动点击进入现有在线搜索，不因库内无结果自动访问外部来源。

## AI 与隐私

AI 开关默认关闭，本机记住偏好。开启开关或输入文字不会自动调用模型；按回车或点击搜索才解析条件。
云端仅接收当前查询（最多 500 字符）和固定的条件字段说明，不发送片库、字幕、文件路径或观看记录。
缓存区分范围、服务商、模型、地址与年份。AI 未配置、解析失败或停止时保留基础结果；面板显示真实的解析等待状态。

私密路由或正在播放私密内容时，只允许私密本地范围，强制关闭云端增强，不覆盖普通模式保存的开关偏好。
切换路由或隐私上下文时关闭面板。CLIP 的描述与图片在本机处理。

## 验证与后续

回归覆盖意图权重、规则条件、精确片名、版本去重与手动拆分、来源隔离、就绪 / 缺失 CLIP、时间点播放、
取消与迟到响应、AI 缓存及私密拒绝、输入法回车、焦点与快捷键。测试使用模拟模型 / bridge，不能替代真实媒体库和模型验收。

本阶段未新增字幕全文索引、简介向量模型、AI 精排、云端识图、库外追更 / 转存或助手结果追问。
助手找片技能的服务统一属于后续阶段。现有助手与片库内自然语言入口仍可使用。

性能目标是热库片名 / 人物查询 P95 ≤ 50ms，需要用真实媒体库实测；120ms 输入防抖单独计入端到端首屏耗时。
尚无真实 200 条查询评测集，本阶段不宣称达到命中率或耗时目标。
