# mpv 对应源码分发

用户已同意更换可追溯的 mpv 构建来源，保留现有播放功能。

## 设计

采用 MSYS2 UCRT64 的 mpv 0.41.0-10。锁定实际运行所需二进制文件及其所属包，按官方仓库 SHA-256 校验下载；每个所属包的完整源包按其版本匹配，并核对源包 PKGBUILD 与二进制 .BUILDINFO 中的哈希。保留源包中的上游源码、补丁及配方。

运行时仅装入 PE 导入图所需 DLL，加上 Vulkan 加载器。Windows 系统 DLL 不再分发，尤其不带旧 d3dcompiler_43.dll。使用 MSYS2 的目录布局，播放器路径为 bin/mpv.exe。

源码集合、包元数据、构建说明和许可原文直接进入安装包的 resources/third-party。不是书面源码要约，也不以浮动上游链接代替对应源码。

## 执行与验证

1. 生成含二进制与源包哈希的分发锁文件。
2. 共用下载、校验、解压逻辑；迁移开发下载器和应用内安装器。
3. 构建时生成并检查源码集合及许可清单；更新发行文档。
4. 验证损坏包拒绝、原子安装和已安装版本识别；以真实 mpv 验证 IPC、解码、D3D11 与高质量缩放。
5. 类型检查、测试、构建、工程检查及实际安装包资源检查。
