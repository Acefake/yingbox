# 独立更新窗口实施记录

目标：安装期间持续显示影盒动态 Logo，旧进程退出后仍可见，完成后自动打开新版。

1. `src/main/updater/companion.ts` 在安装目录外准备独立运行时，页面挂载并完成首帧后才让主进程退出；按 PID 清理已退出的历史运行时。
2. `resources/update-companion` 等待旧进程退出，启动静默安装器，完成后退出，失败时显示错误。渲染入口为 `update.html`，复用 88px `UiBrandLogo` 和深色玻璃材质；不展示进度条。
3. `build/installer.nsh` 区分独立窗口安装与直接启动安装包，保留普通安装和退出时静默安装。
4. 用独立 appId 的临时测试包验证安装与自动启动，不覆盖实际影盒安装；运行更新模块测试、类型检查及生产构建，独立只读评审启动及失败路径。
