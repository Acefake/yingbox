# 独立网盘追剧实施计划

已获用户「开始全部修改」授权，在现有工作区实现，保留其他任务的未提交改动，不提交、不发布。使用 writing-plans / executing-plans。

1. 新增 `src/main/autograb/catalog.ts`：TMDB 剧集搜索、元数据和季集缓存；`calendar(range, tasks)` 按主动创建的任务生成分集，媒体库只补本地文件信息。复用共享 HTTP 与网络优化配置，不创建片库占位。
2. 新增 `migration.ts`：状态 v1 到 v2，保留原数字任务句柄，记录可选 libraryItemId；业务去重按 TMDB id。新任务数字句柄由状态分配，不使用片库条目 id。旧取消记录移除，无明确主动追剧证据的分集不启用；迁移原子保存并保留 v1 备份。
3. 修改 `state.ts/deps.ts/service.ts/index.ts/records.ts`：任务元数据入状态；注册端直接匹配 TMDB 并调用服务创建任务。全局策略只影响已创建任务。删除任务清理设置、分集、补全集队列与内存进度；取消中的异步结果不能恢复任务或继续转存。
4. 修改 `target.ts/saver.ts` 与注册依赖：直接使用任务元数据和 115 目录；没有关联库时不查询片库目标、不跟进入库、不报未入库错误。保留合集优先、单文件转存、目录同名检查、限额和撤销边界。
5. 修改共享契约及 Vue 调用方：显式区分任务句柄与 libraryItemId；媒体库详情创建/复用任务，取消真正移除任务。删除缺库引导；未选网盘目录时就地选目录。海报与名称来自任务。日历展示独立任务分集，库条目标记通过关联映射。
6. 更新规格、ADR（取代0049，修订0029相关身份约束）。验证命令：聚焦新增的无库/迁移/取消测试，追更及日历模块 Vitest，Node/Web 类型检查，变更文件 ESLint、check:style/check:case；构建桌面和server/Web产物。自审完整差异后进行只读独立评审。
