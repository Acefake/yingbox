# 1.0.1 发行与 NAS 双入口修复

基线：`197fdd30`。用户已授权此前讨论的双入口修复、验证和重新发行；Windows 使用 `1.0.1`，NAS 使用 `1.0.1-nas.1`，均发布到 Acefake/yingbox。

## 实现

1. 在 `tests/server/dual-origin.test.ts` 记录失败：配置绿联 HTTPS 来源后，内网 HTTP 的登录和片库 RPC 仍须通过；远程入口写 Secure Cookie，内网入口的 Cookie 不加 Secure；其他来源及伪造转发头仍返回 403。
2. `src/server/http/auth.ts` 复用完整来源校验，接受请求本身的来源或显式远程来源，不读取 X-Forwarded-\*。Cookie 优先依据通过校验的 Origin，缺失时保留 HTTPS 配置兜底。
3. `src/server/app.ts` 在配置远程来源时，让现有网页 URL-token 登录通过同源 POST 换 Cookie，避免代理改写 Host 后 GET 无法确定入口协议；令牌 URL 的静态响应不缓存、不带 Referer。未配置远程来源时保留直接 302 换 Cookie 的行为。更新对应注释与部署说明，无 token 模式不变。
4. 运行服务模块回归、完整类型检查、相关 ESLint 和自审；委派只读独立复审。全量测试与构建复用无变化结果，变更部分按需复验；既有三个超长文件的门槛失败单独记录。
