# 手机端布局修复实现计划

目标：消除手机端导航遮挡、内容裁切和过小触控区域，让详情首屏可播放，返回与前进恢复详情及原列表。

范围：复用现有 Vue 组件和设计令牌，不改服务端协议、依赖和播放器策略。

- [x] 外壳：手机横屏维持抽屉导航；详情页隐藏外壳菜单与底栏，详情顶栏保留返回。
- [x] 详情：路由历史保存条目；小海报与标题并排，播放和选源跨列展示，简介可展开。
- [x] 布局：首页缩略图可横滑，类型面板限制在可用宽度；触控控件至少 44px，设置避让安全区。
- [x] 验证：路由后退/前进回归测试，模块测试、类型检查、全量测试、构建和工程检查；Chromium 模拟手机竖横屏确认布局。
- [ ] 交付：检查 diff，中文提交并推送，创建可审查的 PR，说明真机 Safari 与播放器手势尚未验证。
