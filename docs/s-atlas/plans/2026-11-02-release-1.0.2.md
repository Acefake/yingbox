# 1.0.2 发行

基线：`13932051`。用户已授权发布 Windows `1.0.2` 到 Acefake/yingbox；本机没有 Docker，NAS 镜像 `1.0.2-nas.1` 不在本次范围，等有 Docker 的环境单独发。

## 本次包含

1.0.1 以来的用户可见变化（`git log v1.0.1..HEAD`）：

- 片库支持电影与剧集混合库；新建片库按文件自动识别，侧栏按内容类别（纪录片 / 综艺 / 动漫 / 电影剧集）分页，媒体库设置合并到「设置 → 媒体库」。
- 片库页头只留扫描 / 识别 / 视频墙，筛选、排序与想看收进「全部」一段；切换筛选不再跳回页顶。
- 自动追更拆成独立页面：待处理集一张卡、总览与单剧侧板重做，剧按分类追更，洗版挪进设置；追剧日历按新设计稿重做。
- 首页分开热门电影与热门剧集，大图评分改成与海报同款来源角标。
- 桌面与 NAS 统一影片搜索与资源聚合，查询显示提交状态并阻止重复查询。
- 在线数据源每次启动后台检测并自动启停；115 目录可入库、扫描刮削与 Range 播放。
- 修复：海报墙首行悬停被裁、网盘文件读不回来时后台指纹任务清不完、追更页重复剧与旧设置丢偏好、混合库的剧不进追剧日历、从设置登录回来追更页不刷新。
- 窗口键改成 Windows 原生样式，页头控件改玻璃底，标题字号统一。
- 服务端：独立的 Node 后端安装包；NAS 目录读取错误按码返回，网页视频绕过静态缓存。

## 实现

1. `package.json` 版本提升为 `1.0.2`，不升级依赖。
2. 全量类型检查、ESLint、单元测试；既有门槛失败单独记录，不抬高限制。
3. `fetch:mpv` + `electron-builder --win` 构建 NSIS 安装包，产物为 `yingbox-setup-1.0.2.exe`、对应 `.blockmap` 与 `latest.yml`。
4. 校验 `latest.yml` 的更新源（Acefake/yingbox）、版本号与文件哈希，比对 EXE 实际 SHA-256；在隔离数据目录启动解包后的程序，确认主窗口正常。
5. mpv 源码包复用 `resources/mpv-sources/msys2-ucrt64-mpv-0.41.0-10-20261028-sources.tar`（与 1.0.1 同一份，随发行上传）。
