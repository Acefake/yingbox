# mpv 高质量缩放

用户已确认采用 mpv 内置缩放，移除外部着色器功能。

1. 用单一 `player.highQualityScaling` 布尔设置和 IPC 替换着色器配置。
2. 新进程和运行中切换均使用 `ewa_lanczossharp`；关闭使用 `lanczos`。保留 RTX 超分。
3. 设置页复用 SettingsRow / UiSwitch，展示“高质量缩放”。删除下载器、着色器注册表和动画分类传参。
4. 验证启动、切换、重启行为，运行类型检查、测试、构建和工程检查。

旧设置由现有 schema 校验忽略，下一次设置写入时从文件移除。已下载的用户缓存不再读取，不主动删除用户目录。
