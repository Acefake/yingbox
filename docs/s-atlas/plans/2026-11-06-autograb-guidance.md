# 追剧引导与合集优先展示

目标：缺少剧集库时提供媒体库设置入口；追剧侧板先呈现合集流程，合集候选在补搜单集前转存。沿用 ADR-0049、0050，不整体转存分享目录。

1. `tests/autograb-pack-first.test.ts`：断言不完整合集中的候选先转存，再搜索剩余单集；检查搜索中的合集进度及结束结果。先运行新测试确认失败。
2. `src/shared/contract/autograb.ts` 新增可选合集进度；`pack-round.ts` 暴露内存进度，开始、完成、失败时通知；`overview.ts`、`service.ts` 传递进度，已有自动转存阶段移到合集搜索之后、单集搜索之前。保留确认、暂停、空间与次数限制。
3. `use-online-tracking.ts`：去掉 IPC 错误包装；缺剧集库时用既有确认框说明用途，确认打开 `library` 设置分区，取消留在详情页。说明既有纯电影库可开启「自动识别类型」。
4. 新增 `series-progress.ts`、`SeriesPackProgress.vue`：用真实合集进度与阻塞条件显示状态；侧板分集明细默认收起，可展开操作。桌面、Web/NAS 共用；Android/TV 当前没有原生自动追更入口，不新增另一套功能。
5. 运行追更模块 Vitest、Node/Web 类型检查、变更文件 lint、样式检查；审阅完整任务差异与关键调用方，再派只读独立评审。现有其他未提交修改保留。

验收：不存在缺库时的内部 IPC 报错；可一键进入媒体库设置；合集搜索期间有真实状态，完成后说明匹配集数；有合集候选时先转存，再补搜遗漏集；分集明细保持可访问。
