# 豆瓣独立首页实现计划

目标：未配置 TMDB 时，首页列表、轮播和在线详情仍可展示豆瓣内容；保持现有布局、海报比例和选源播放入口。

方案：复用豆瓣 rexxar / frodo 解析与网络层，新增有缓存和并发合并的详情接口。列表立即显示豆瓣封面，首页前五项按需补简介及横图；详情按豆瓣 ID 加载。TMDB 仅增强已有内容，失败不抹掉豆瓣数据。

- [x] 引擎：详情响应映射、缓存、失败降级、契约校验与测试。
- [x] 首页：豆瓣初始字段、有限数量详情补全、TMDB 可选合并与测试。
- [x] 详情：豆瓣简介、评分、演员及剧照展示；切换条目时丢弃旧请求。
- [x] 验证：类型检查、相关与全量测试、构建和样式检查；记录实测接口与运行环境限制。

约束：不改其他未提交修复，不新增依赖，不提交代码。无横图时保留原有封面兜底；不伪造 TMDB ID，不把豆瓣评分标成 TMDB。

验证记录：相关 51 项测试通过；类型检查、构建、ESLint、样式令牌、导入大小写和文件大小检查通过。全量 3719 通过、26 失败、11 跳过，失败集中在路径、部署和其他模块，未在本任务修改。真实豆瓣接口验证成功；无 TMDB 的组件浏览器检查覆盖深浅主题与竖海报兜底，尚未运行完整 Electron E2E。
