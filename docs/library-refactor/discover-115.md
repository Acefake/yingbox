# 库外发现：豆瓣找片 + 115 转存入库

AI 助手在本地库里找不到或找得不够时，按豆瓣筛选找库外的片子；用户确认后只把选中的那个文件转存到 115，再由媒体库扫描入库。在线首页的豆瓣电影卡右上角也有同一个「找 115 资源」入口。只有桌面端（115 会话在主进程）；私密模式不接这条链路。

## 前提

- 设置 · 网盘：填 PanSou 地址、扫码登录 115；
- 「助手转存目标文件夹」（设置 · 网盘）在媒体库里（CloudDrive2 挂载，媒体库存储设为「网盘」）；没设时跟随网盘的转存位置；
- 建议配好 CloudDrive2 webhook；没配也行，转存 10 分钟后会主动通知媒体库扫描。

## 流程

1. **找片**（renderer `features/assistant/skills/discover-skill.ts`、`features/discover/`）：助手动作 `discover.discover`，模型在 command 槽写「类型=科幻;年代=90年代;排序=评分」，按 `shared/douban/query.ts` 白名单收（别名先换成白名单写法）。豆瓣出片单（中文片名、评分、年份、海报），TMDB 只补 id 与原名（没令牌时跳过），和本地库（tmdb 来源）按 TMDB id 或片名 + 年份去重。库里有的给「播放」卡片，库外的标「未入库」，带「找 115 资源」和「在线看」（跳在线搜索）。
2. **找资源**（main `src/main/discover/`）：复用追更的 PanSou 搜索、分享快照与 115 闸门（同一队列、每日限额与熔断、同一张拉黑表）。关键词「片名 年份」「片名」「原名 年份」；认文件规则见 `movie-rules.ts`：片名（中文或原名）与年份对得上（允许差一年）、排除预告 / 花絮 / 枪版 / CAM 等、500 MB–60 GB；按分辨率、中字、片源、体积打分，返回前 3 个。
3. **转存**：用户点「转存」才存；先列目标文件夹，同名已在就不存；只传那一个 file_id；候选留在主进程，渲染层只回传 searchId 与序号。
4. **入库**：转存 10 分钟后按 115 路径通知媒体库；渲染层每分钟按片名查一次媒体库，卡片角标从「入库中」到「已转存，等待入库」，查到后变「已入库」并给「播放」。

## 还没做

- NAS 服务端；
- 转存后的入库跟进只在内存里（重启后不再主动通知，靠 CloudDrive2 webhook 或下次扫描）。
