新增
- 桌面端默认用 mpv 播放，全格式硬解与 ASS 特效字幕开箱可用；想换回内置播放器可在设置里改
- mpv 控制条可在外观里切换 uosc / ModernZ / mpv 自带三种，界面固定简体中文
- mpv 常驻预热：点播放只换片，不再每次等窗口启动；关窗后回到待命，可在设置里关掉
- 安卓手机与电视的播放界面重新设计：手机顶部一排图标点开即选，中间三个大圆钮，底部一条细进度条，横滑屏幕就能拖进度；电视只用遥控器方向、确定、返回三个键，按住左右键越拖越快

优化
- 打开 mpv 的等待画面改为玻璃卡片，左边循环品牌标志、右边显示正在启动
- 追更列表显示已完结的剧，并把在追的剧按最近播放排序，播过的排在前面
- 播放引擎设置里 mpv 排在第一个
- 详情页头图去掉「想看」，只保留「追更」

修复
- mpv 窗口等第一帧就绪再出现，探测新文件时不再先黑屏
- 日历把同日多集合并时不再读取缺失的入库信息，已入库完的剧自动收起
- AI 未就绪时搜索入口不再显示 AI 文案
