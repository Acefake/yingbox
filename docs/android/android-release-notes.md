安卓原生首版，手机与电视共用一个应用，安装后自动适配触摸或遥控器布局。

- 首页浏览、搜索、详情、播放源测速与选集。
- 原生播放器、继续观看、收藏、图片清晰度与 TMDB 设置。
- 数据源自动检测与手动屏蔽。
- 应用内更新：启动提示、设置中手动检查、下载进度、大小和 SHA-256 校验，系统确认安装。

安装 ARM64 手机、电视或盒子请选 `arm64-v8a.apk`；x86_64 设备或模拟器选 `x86_64.apk`。暂不支持 32 位 ARMv7。所有 APK 均使用固定发布签名，后续版本可覆盖更新。

本版本在 GitHub 分类为 Pre-release，以隔离桌面端更新源。安装时由系统请求允许影盒安装应用，更新仍需用户在系统安装器确认。更新查询和下载需要设备能够访问 GitHub。

已安装调试签名测试包的设备不能直接覆盖为本正式签名包，卸载前请自行保留需要的数据。ARM64 产物已核对 ABI 和签名；ARM 真机及杜比视界硬件能力仍需实机验证。
