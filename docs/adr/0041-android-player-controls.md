# ADR-0041 安卓播放器控制层：Compose 自绘，手势与遥控器共存

- 日期：2026-11-03
- 状态：已采纳（控制层布局、手势范围与遥控器键位已被 [ADR-0056](0056-android-player-controls-redesign.md) 取代，其余决策仍有效）
- 部分取代：ADR-0056 取代本 ADR 的决策 4（设置面板形态）、决策 5（触屏手势范围，新增横滑拖进度）、决策 6（遥控器键位）；决策 1（关掉自带控制条）、2（播放状态进 `PlayerState`）、3（纯函数徽标）、7（沉浸式横屏）、8（手动换集先停旧媒体）继续有效
- 相关：ADR-0039（播放内核）、ADR-0040（NAS 片库）、ADR-0016 / ADR-0018（桌面播放器）

## 背景

安卓播放界面用 media3 自带的 `PlayerView` 控制条：没有音轨、字幕、倍速、画面比例入口，看不到杜比视界、HDR、Atmos 这类信息，也没有手势。

## 决策

1. **关掉 `PlayerView` 自带控制条**（`useController = false`），画面仍由 `PlayerView`（`SurfaceView`，HDR 与杜比视界的前提）渲染；控制层是盖在上面的 Compose。在线播放（`PlayerScreen`）与片库播放（`LibraryPlayerScreen`）共用 `PlayerHost`，一次改两边都有。
2. **播放状态进 `PlayerState`**：想播放（`playWhenReady`，缓冲时按钮也是「暂停」）、正在播放（只用于自动隐藏）、倍速、画面比例、轨道。进度只在控制层可见时每 500 ms 轮询。
3. **信息徽标是纯函数**（`playbackBadges`）：分辨率按宽度分档（宽银幕片也是 4K），动态范围带杜比视界 profile，音频只标 Atmos、TrueHD、DTS 系列、EAC3、AC3；`formatClock`、`gestureDelta` 同样是纯函数，有 JVM 单测。
4. **设置面板**：音轨、字幕（含「关」）、倍速、画面比例、统计信息；音轨与字幕直接用 ADR-0039 的 `Tracks.options` / `Player.select`。
5. **触屏手势**：单击显示或隐藏控制层，双击左右半屏快退快进，长按两倍速（松手恢复），左半屏竖滑调亮度、右半屏竖滑调音量。手势层在控制层下面，按钮和进度条自己消费事件。手势不唤出控制层，提示（亮度、音量、快进快退）画在控制层上面。
6. **遥控器**：焦点在根容器时，左右键快退快进、确定键暂停、上键开设置；按下键把焦点送进控制层，这时方向键换按钮、确定键按按钮。设置面板打开时控制层让开，焦点送进面板，关闭后焦点还给根容器。任何按键都会唤出控制层，4 秒无操作自动隐藏（暂停、拖进度条、面板打开时不隐藏）。
7. **全屏播放。** 进入播放页就沉浸式：隐藏状态栏和导航栏（从屏幕边缘滑一下临时唤出），画面铺进刘海区域，屏幕锁成横屏（`SENSOR_LANDSCAPE`，跟着重力在两个横向之间翻转，不受系统「自动旋转」开关影响）；控制层右下角的按钮可以切到竖屏（仍然隐藏系统栏）。离开播放页时系统栏、刘海模式、屏幕方向都恢复。控制层与返回按钮避开刘海。电视本来就是横屏，不受影响。
8. **手动换集先停旧媒体。** 手动上一集 / 下一集先上报进度，再停掉并清空播放器，在线播放还清掉换源中的续播位置，避免旧集继续出声、多跳一集或误触发换源。

## 后果

- 图标：播放、设置用生成的 Phosphor 图标；暂停、上一集、下一集、快退、快进用 Material 的基础图形（Apache 2.0）手写在 `PlayerIcons.kt`，不进图标生成脚本。
- 不做：片头片尾跳过、画中画、MediaSession 通知、字幕样式与延迟、章节。
- 手势、遥控器焦点没有自动化测试（仓库只有纯 JVM 单测），靠真机清单验证（`android/README.md`）。

## 否决方案

- **在自带控制条上改样式**：入口（音轨、字幕、倍速）与徽标加不进去，遥控器焦点也不好管。
- **手势层放在控制层上面**：会挡住按钮和进度条，要逐个转发事件。
