# ADR-0050 追更缺多集时先找合集，只存缺的集

- 日期：2026-11-05
- 状态：已采纳
- 补充：[ADR-0029](0029-autograb-target-and-organize-home.md)；设计见 `docs/s-atlas/specs/2026-11-05-autograb-pack-first-design.md`

## 背景

追更每一集单独搜、单独存。存整部已完结的剧要几十次搜索与快照，经 115 闸门限速后要几个小时；整季包虽能认，
但只用来挑出当前这一集。

## 决策

1. 一部剧到点的缺集 ≥ 2 集时，先找合集分享（`pack-finder.ts`）：点开后把全部视频对每个缺集认一遍，认到的集直接带候选，
   走原有的确认 / 全自动流程。
2. 转存仍是一个文件一次（`saver.grab`），只存缺的集；合集没覆盖的集退回逐集搜。
3. 同一部剧 6 小时内不重复找合集（内存里记，重启后重找）。

## 后果

- 存整部剧的搜索 / 快照次数从每集一次降到每个合集一次；转存仍逐文件，受 115 闸门限速。
- 合集里认不出集号的文件不会被存。
- 单集更新的路径不变。

## 否决方案

- **整个合集文件夹全存**：会存进花絮、重复清晰度，之后还要整理去重。
- **存完再删重复**：多占空间，且引入删除操作。
- **只搜合集、不退回单集**：连载剧的合集更新滞后，新集会更晚到。
