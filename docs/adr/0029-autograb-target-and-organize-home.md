# ADR-0029 追更转存按剧定位，整理并入已有剧文件夹

- 日期：2026-11-02
- 状态：已采纳
- 相关：ADR-0012（片库任务后继）、ADR-0020（服务端网盘与追更）

## 背景

追更给每部剧记一个 115 文件夹 cid，转存时把文件平铺进去。整理会把文件挪进按模板命名的新文件夹、删掉清空的旧文件夹，
这个 cid 随即失效；片库重建换了条目 id 时单独设置也可能丢，落回剧集默认目录。默认目录常常就是媒体库根目录，
于是新集散落在根目录。整理只看单个本地条目，按文件当前位置 + 模板算目标，散放的新集会在当前位置另建一个剧文件夹，
不会并回这部剧已有的文件夹。

## 决策

1. **追更转存目标按优先级解析**（每次转存时现算，不再只信存下来的 cid）：
   1. 片库里这部剧（同 TMDB id 的合并成员）已有的剧文件夹，有这一季的季文件夹就用季文件夹；本地路径经挂载根目录或
      115 根目录同名匹配换算成 cid（`upgrade/folder-path.ts`）；
   2. 用户为这部剧手选的文件夹，先核对它在 115 上还在；
   3. 分类默认目录 / 剧集默认目录下的「剧名 (年份)」子文件夹（名字取整理模板第一段，整理时不会再改名），没有就建。
      只有「明确没有」才往下一步走；查询出错（网络、风控、片库没响应）、换算或建文件夹失败时这一集记转存失败，
      下一轮再试，不退回根目录。手选的文件夹不在了、兜底目录又是 115 根目录时报错让用户重选。
2. **电影追更**存到电影默认目录下的「片名 (年份)」子文件夹，不再平铺。
3. **整理剧集时先找「家」**：同一媒体库里同 TMDB id 的条目中，视频最多的剧文件夹是这部剧的家；目标改成
   「家文件夹 / 模板里季及以下的部分」（家里已有这一季的文件夹就进它），沿用家文件夹现有的名字。
   条目的视频都在家里时照常按模板整理；同一批里家文件夹自己也改名时，散存的集跟到新名字。
4. **分类文件夹不当剧文件夹**：剧集文件直接放在名字是明确分类词的文件夹（大陆、韩剧、美剧、动漫、综艺、纪录片、
   剧集……见 `CATEGORY_FOLDER_RE`）里时，这个文件夹是分类文件夹；分组按剧名，整理以它为基准。电影整理时另用 TMDB 片名
   核对：主视频直接所在的文件夹不带年份、不像发布包、名字也不是这部片的片名，就当分类文件夹。
5. **电影整理**：只有文件名带分段标记（cd1 / part1 / disc1）才加 ` - partN`，否则是多版本，用画质 / 来源标签区分；
   远小于主视频的视频（< 最大者 5% 且 < 200 MB）当广告排除；电影也保留分类文件夹作基准。

## 后果

- 追更页上「转存位置」变成兜底位置：片库里已有这部剧时实际存到剧文件夹。
- 规则 4 会改变部分散放文件的分组键，下次扫描重新归组。
- 新增 115 建文件夹接口（`/files/add`），只在默认目录下建一层「剧名 (年份)」/「片名 (年份)」。

## 否决方案

- **只在转存前核对存下来的 cid 还在**：能避开已删除的文件夹，但整理改名后旧 cid 仍可能指向空壳或别的位置，散存问题照旧。
- **转存时直接建到模板的季文件夹**：多一层建文件夹请求；整理本来就会把文件挪进季文件夹，只建一层「剧名 (年份)」就能让整理原地完成。
- **按「文件夹名和文件里的剧名对不上」认分类文件夹**：「繁花」里放 `Blossoms.Shanghai.S01E01` 这类中文文件夹 +
  英文发布名的常见布局会被误判，只认明确的分类词。
- **整理时跨媒体库并入**：会把文件挪出原媒体库，库的根目录和自动化设置都对不上，只在同一媒体库内找家。
