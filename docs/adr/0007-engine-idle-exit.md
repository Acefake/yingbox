# ADR-0007 后台引擎空闲 5 分钟退出

- 状态：已采纳（2026-10-22）
- 相关：PR #59、#61

## 背景

后台引擎（在线源、MissAV、下载）首次调用时启动，之后一直常驻，空闲时也占约 39 MB 私有内存。

## 决策

没有调用在途且引擎没有报忙时，最后一次调用结束 5 分钟（`ENGINE_IDLE_MS`）后发 shutdown；任何调用重置计时。下载队列在有任务运行或排队时报 `busy`。关停超过 5 秒未退出就 kill；关停中到来的调用等旧进程退出后再 fork 新进程，不让两个引擎同时写 `queue.json`。媒体库引擎不空闲退出（它持有目录监控与订阅）。

## 后果

- 不用在线功能时省下整个引擎进程的内存；下一次调用多付一次启动（约 0.1–0.5 s）。
- 依赖「下载报忙」的正确性：漏报会在下载中途关停，好在下载已能续传（ADR-0006）。

## 否决方案

- 常驻：浪费内存。
- 更短的空闲时间：频繁冷启动，在线浏览时体感变慢。
- 媒体库引擎也空闲退出：会丢目录监控和事件订阅，重开代价大。
