# ADR-0053 独立更新等待窗口

- 日期：2026-11-06
- 状态：已采纳
- 部分取代：[ADR-0045](0045-desktop-silent-auto-update.md) 决策 2 的全窗口安装画面。

## 背景

旧应用退出后，进程内的加载界面随之消失。安装期间需要继续显示影盒的品牌动画；用户选择只保留动态 Logo 和提示，不显示进度条。

## 决策

1. 更新窗口在安装目录外的独立 Electron 运行时运行，复用 `UiBrandLogo`、玻璃材质和设计令牌。Logo 为 88px，浮动与扫光持续循环，遵守系统减少动态效果设置。
2. Vue 挂载和首帧绘制完成后才显示窗口并通知主应用退出；随后等待旧进程退出，执行安装包。安装期间不占用安装目录内的 EXE、DLL 或页面资源。
3. 安装器继续使用 `/S --updated --force-run`；独立窗口通过 `YINGBOX_UPDATE_UI=1` 请求静默安装。安装完成自动启动新版并关闭等待窗口，失败时显示错误和关闭操作。普通安装向导与退出时的 `/S` 安装保留。
4. 设置页显示主进程报告的当前版本；手动检查绕过发布列表缓存，后台检查保留缓存。
5. 独立运行时按应用版本缓存，后续更新准备时根据记录的 PID 清理已退出的历史版本；仍在运行或状态无法确认的目录保留。

## 后果

首次更新需复制运行时到用户数据目录，增加准备时间和磁盘占用。动态 Logo 表示正在安装，不代表文件处理百分比。安装期间的窗口由独立进程承载，主应用退出不会销毁它。

## 否决方案

- 主窗口内播放动画：旧进程退出后无法继续显示。
- 原生安装进度页：无法直接复用主窗口的 Vue 动态 Logo 与玻璃材质。
- 安装百分比进度条：用户选择只保留动态 Logo 和安装提示。
