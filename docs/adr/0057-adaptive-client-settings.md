# ADR-0057 客户端基准下的自适应设置

- 日期：2026-11-07
- 状态：已采纳
- 部分取代：ADR-0033 的设置页面布局决策

## 背景

桌面使用分类导航与内容区，安卓把全部选项展开，手机网页把设置分类横排。手机、iPad 与电视需要统一分类和材质，并保留适合各自输入方式的布局。

## 决策

以客户端令牌和组件语义为基准。手机设置采用分类列表与逐级页面，平板和电视采用分类、内容双栏。安卓保持设备设置与服务端设置各自的持久化规则、保存失败回滚和现有功能。分类只展示当前平台已实现的能力。

浮动设置外壳复用玻璃材质，内容分组保证对比度；降低透明度时使用实色。电视的返回键先回到分类焦点，手机返回键先返回分类页，随后才离开设置。iPad 分屏缩窄时使用手机布局。

## 后果

Vue 与 Compose 各自实现相同视觉语义，尺寸和焦点行为依设备调整。修改布局不迁移设置数据、不增加新的服务接口。

## 否决方案

全部平台复用同一长列表无法满足手机信息组织及电视遥控器定位。为每端另建视觉规范会持续造成组件与状态差异。
