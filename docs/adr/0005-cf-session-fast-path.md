# ADR-0005 过挑战后 25 分钟内走 session.fetch 快路径

- 状态：已采纳（2026-10-22）
- 相关：PR #66；参考 Peach ADR-0065（cf_clearance 约 30 分钟，绑定 UA 与出口）

## 背景

浏览器代抓（`src/main/browser-fetch/`）每个请求都开一个隐藏窗口渲染，同一主机连续请求也一样，慢且占资源。

## 决策

窗口取到正常页后按主机记时；25 分钟内先在同一 partition、同一 UA 下用 `session.fetch`（credentials include）直接取页，用 `classifyPage` 判定：ok 直接返回；challenge 作废记录、退回窗口；blocked 立即熔断、不开窗口；出错、非 2xx 或空白页退回窗口（记录保留）。成功不续期。会话直取不排队、可并发，窗口仍串行；排队中的请求发现记录已更新，先再试一次会话，同主机并发撞挑战只开一个窗口。

## 后果

- 本地模拟实测：同主机后续 20 次请求从每次开窗口（中位 91 ms）降到中位 4 ms、0 个窗口。
- 真实 Cloudflare 是否接受 `session.fetch` 发出的请求头只能实机验证；不接受时退化为每次开窗口，与改动前相同。
- 记录只在内存里，重启后第一次仍开窗口。

## 否决方案

- 记录成功即续期：会超过 cf_clearance 的真实有效期，换来更多被挑战的请求。
- 把 cookie 回灌给引擎的 `net.fetch`：跨进程同步 cookie 与 UA，复杂度更高，收益相同。
- 加「要渲染」参数：调用方（MissAV、下载源、CatSpider 直连）都只解析原始 HTML，没有人需要渲染结果。
