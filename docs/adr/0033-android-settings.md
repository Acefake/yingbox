# ADR-0033 安卓设置：设备设置存本机，服务端设置走 /api/server-settings

- 日期：2026-11-03
- 状态：已采纳
- 相关：ADR-0028（安卓端方案）、ADR-0030（视图域）

## 背景

安卓端要有设置页。桌面的设置分三类：只跟本机界面有关的（主题、悬停预览、播放器窗口）、主进程密钥（TMDB 令牌、各服务商 API Key）、服务端要读的（元数据语言、图片清晰度、网盘与通知）。独立服务已经为网页端暴露 `GET / POST /api/server-settings`，键集是 `shared/settings/server-keys.ts`，值按桌面同一套 `parseSetting` 校验。

## 决策

1. **按谁读这个值来分。** 服务端要读的键（现在只接了 `scrape.metadataLanguage`）走 `/api/server-settings`，与桌面、网页端同一个键、同一组取值，校验在服务端，客户端不重复。只跟这台设备有关的设置存应用自己的 SharedPreferences（`DeviceSettings`），不进服务端：降低透明度（`ui.reduceTransparency`）、自动播放下一集（`player.autoNext`）。键名沿用桌面设置的名字。
2. **设置页是第 4 个主导航项**，用实色分组卡片 + 开关 + 胶囊选择，不画分隔线；开关和胶囊都可聚焦，电视遥控器可用。
3. **降低透明度** 让 `ybGlass` 用实色底、不做背景模糊，由 `LocalReduceTransparency` 传下去；系统层面安卓没有对应的全局开关，不跟随系统。
4. **改失败回滚。** 服务端设置写失败（400、服务没起来）时退回改之前的选中并提示。

## 后果

- 两类设置的存放位置要看键：新加设置时先看服务端会不会读它，会读就进 `SERVER_SETTING_KEYS`，不会读就放设备设置。
- 这几个设备设置不跨设备同步，换手机要重设。
- 暂不接：TMDB 令牌（要文字输入，电视上要配对流程）、图片清晰度和片库相关项（等安卓有片库再加）、网盘与通知。

## 否决方案

- **全部存服务端**：降低透明度、自动下一集是每台设备自己的偏好，一台电视和一部手机不该互相改。
- **全部存本机、同步给服务端**：服务端要读的键只有一个真相，放服务端最简单。
