# ADR-0045 桌面端自动下载与静默更新

- 日期：2026-11-04
- 状态：已采纳
- 补充：ADR-0038 决策 5（更新器）

## 背景

桌面更新要用户先点「检查更新」再点「下载」，装的时候还要走一遍安装向导。目标体验：发现新版后台下载，下载好后一键「更新并重启」，不出安装向导，装完直接进入新版。

## 决策

1. **自动检查与下载**：启动后检查一次，之后每 6 小时检查一次；发现新版且设置 `update.autoDownload`（默认开）为开时，主进程自动下载，沿用 ADR-0038 的 SHA-256 校验。开着自动下载时不再弹「发现新版本」对话框。
2. **静默安装**：「更新并重启」以 `/S --updated --force-run` 启动安装包后退出本应用，安装包装完拉起新版。画面上由全窗口的「正在安装更新」盖住这几秒。
3. **退出时顺带安装**：开着自动下载且已有校验通过的安装包时，应用退出以 `/S`（不带 `--force-run`）启动安装包，下次手动启动即为新版。点过「更新并重启」后不重复安装。
4. **每用户安装**：NSIS 设 `allowElevation: false`，只装给当前用户，静默更新不需要管理员权限，不弹 UAC。
5. **界面**：后台下载和就绪时在窗口右下角显示更新条，设置 → 软件更新增加「自动下载更新」开关。
6. **macOS 不变**：无签名公证，仍不提供应用内更新（ADR-0038 决策 7）。

## 后果

- 之前整机安装（装在 Program Files）的用户，新安装包不再提供「所有用户」选项；按每用户安装的新版与旧的整机安装会并存，需要先卸载旧版。
- 静默安装失败时只能由安装包自己的行为决定；启动安装包失败时应用保留并提示错误。
- 关闭自动下载的用户，退出时也不会顺带安装。
