# ADR-0003 海外探测失败不当作源失效

- 状态：已采纳（2026-10-21）
- 相关：PR #41（删源）、#44（恢复茶杯狐）

## 背景

开发与自动检查跑在海外出口的沙箱里，用户在北京。#41 按沙箱和 check-host（香港 / 东京 / 洛杉矶）的探测结果删掉了返回 404 的茶杯狐；用户在国内实测可用，404 是站点的地区限制，#44 又恢复了它。

## 决策

海外出口得到的 404、302、超时、连接失败，都不能作为删除源、改地址或判定「源失效」的依据。只有国内实测（用户或国内出口）确认后才删改；海外不通时保留源，运行时由熔断兜底。涉及网络的逻辑用 mock 测试覆盖，不依赖沙箱的真网络结果。

## 后果

- 源清单里会留着海外看不通、国内可能可用的源（如韓劇看看），失效时由按主机 + 用途的熔断（ADR-0004）跳过，不弹窗也不卡搜索。
- 改源地址的 PR 要在描述里列出「需国内实测」的项，由用户在大陆网络确认。

## 否决方案

- 以多地 check-host 结果为准：所有节点都在境外，看不到地区限制。
- 自动删除连续失败的源：同一原因会把国内可用的源删掉，且不可见。
