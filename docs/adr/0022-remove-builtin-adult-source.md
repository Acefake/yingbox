# ADR-0022 移除内置 MissAV 数据源

- 状态：已采纳（2026-10-28）

## 背景

用户要求移除全部 MissAV 浏览、播放和下载功能。专用 `av` 引擎域只服务该内置源。

## 决策

取代 ADR-0019 中有关 `av` 引擎域的开放范围：桌面 IPC 与服务端 HTTP 仅开放 `online` 和 `download` 引擎域。

删除专用目录与播放解析器、下载源、封面拼接、请求头规则及默认源设置逻辑。AV 页面保留 CMS 与插件浏览、搜索、播放；失效的已选数据源回退到可用源。

## 后果

应用不再提供 MissAV 专用接口。已有浏览历史、收藏和下载文件不主动删除；用户提供的通用媒体 URL 仍遵循通用播放、下载规则。

## 否决方案

仅隐藏入口会保留后台专用接口和下载能力，不符合全部移除的要求。
