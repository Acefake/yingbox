# 影盒全项目 UI 重构设计草案

状态：等待视觉方向确认，尚未修改产品代码。

## 目标与范围

基于现有 Vue 3、Ant Design Vue 和 Electron，统一主窗口、在线首页与搜索、收藏与最近播放、电影与电视剧本地管理、Amane 片库及设置、AV 在线资源、详情、数据源、任务队列、全局设置与独立播放器。现有扫描、刮削、筛选、播放、来源管理及成人模式功能保持可用。上游 Amane 子模块不参与视觉改造。

用户明确要求全项目重构、优先使用图标。已确认的 Amane 页面继续使用 Vue，页内导航置顶，不回退为网页嵌入。

## 视觉方向（用户指定参考 Claude Code 桌面端）

参考 Claude Code 桌面端的暖灰、安静的侧栏和轻量工具栏。全局侧栏使用 208px 图标加短名称，可收起到 64px；顶部 52px 工具栏，下面放媒体内容。Amane 页内导航保持顶部横排图标加短名称。图标化首先用于工具操作，而非让初次使用者猜测页面入口。

浅色基准：画布 #FAF9F6、侧栏 #EFEEE9、内容面 #FFFFFF、分隔 #DEDDD5、主文 #292823、次文 #77766F；强调 #A65036 仅用于少量状态。深色基准：画布 #292824、侧栏 #22211E、内容面 #33322E、分隔 #44433B、主文 #EEEDE7、次文 #AAA89D；强调 #E4A58D。主要按钮用深浅反转的中性色。暖灰来自用户指定参考，适配媒体界面而不复制聊天布局。保留现有已保存主题；新用户默认浅色。

字体沿用系统可用字体，不下载依赖：Windows 优先 Segoe UI Variable / Segoe UI，中文 Microsoft YaHei UI；macOS PingFang SC。正文 13px、说明 12px、内容标题 22px、详情标题 28px。字重主要 400/500/600，标题和正文左对齐。

布局采用 4/8px 间距基准，工具按钮 32px，常规输入 36px。面板圆角 10px，海报 8px，输入 6px；静态区域不加投影，弹出层才有阴影。主动反馈动效控制在 120–180ms，遵守 reduced-motion。

│主题│                                                        │

在线首页以内容分区和海报为主，取消堆叠大卡片与重复标题；搜索、收藏和历史采用同一海报组件与工具栏。搜索结果保留来源信息和错误反馈。

电影/电视剧采用可调宽度文件列表和右侧详情。目录、文件、扫描状态使用统一图标；刷新、添加目录、筛选等缩为带提示的图标按钮。详情保留显眼的播放主按钮与短文字，高风险/不可逆操作保留明确文字。

Amane 统一海报卡片、详情、字段控件、顶部导航和高级筛选。筛选区域展开后保持四列、窄宽度降为两列/一列。设置使用紧凑分组导航和表单内容，保存栏统一；站点排序不丢失键盘操作。

设置、来源管理和队列使用统一抽屉尺寸、头部、滚动区与操作区。错误、加载、空状态采用图标、短解释及明确下一步，不输出后端实现术语。

播放器维持视频画面优先，统一控制图标、浮层和焦点反馈；全屏、字幕、音量和快捷键继续工作。播放画布不套用普通页面背景。

## 图标规则

扩展现有 AppIcon，不新增图标依赖。统一 24px viewBox、1.75px 描边，常用尺寸 16/18/20px。刷新、搜索、关闭、筛选、排序、视图、收藏、来源、队列、窗口和目录操作优先图标；为图标按钮提供 title 和 aria-label，保留 disabled/loading。主播放、保存、重试及删除确认保留短文字。替换 emoji、字符箭头和散落的多套 SVG，但不改动影片名称与用户内容。

## 实施边界与检查

按主题 tokens / Ant Design 主题 → 外壳与公共控件 → 在线页面 → 本地电影电视剧 → Amane → 全局设置来源队列 → 播放器顺序实施。直接整理已有组件的布局和样式，不能仅追加一份全局覆盖 CSS 后声称重构完成。保留现有事件、props、IPC、路由和数据持久化。

源码工作延续本会话限制：不运行 typecheck、build、打包，不扫描或处理 node_modules / dist。设计稿预览属于独立 HTML，不代表真实客户端截图。真实客户端视觉和交互验收须明确标记未执行，不把静态检查当作 UI 通过。

当前仓库包含大量已有暂存和未暂存修改。实施前按文件核对 diff，仅修改 UI 范围；不重置、不整理无关后端、不自动提交整个仓库。
