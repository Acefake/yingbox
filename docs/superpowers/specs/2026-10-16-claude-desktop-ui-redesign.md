# 影盒全项目 Claude 桌面端风格重构

状态：用户已确认，源码重构已实施；真实客户端视觉核查待完成。

## 意图

让影盒从在线浏览、电影和电视剧管理、Amane、AV 资源到设置和播放器，呈现为同一款克制、紧凑的桌面应用。用户指定的 Claude 桌面端截图是视觉依据：深色石墨工作区、独立侧栏、轻量顶部工具栏、低对比度分隔、紧凑导航、清楚的主次文字和少量强调色。当前产品以媒体浏览和整理为核心，因此海报墙、文件清单、片库筛选和播放器各自保持适合内容的布局。

## 目标与边界

- 覆盖 Electron 主外壳、全局导航和搜索、在线首页及搜索/收藏/历史、电影与电视剧、本地详情、Amane 片库/演员/文件/任务/智能体/设置、AV 页面、全局设置/数据源/队列、播放器弹窗和空/错/加载状态。
- 保留路由、行为、Vue 组件、IPC、数据字段、主题切换和用户保存的设置；只调整呈现与必要的可访问性语义。
- 延续 Amane 自己的顶部功能导航，主应用使用固定侧栏和轻量窗口工具栏。
- 不修改 Amane 上游，不恢复已删除的 AV 刮削模块，不改变后端和媒体处理流程。
- 图标用于紧凑工具操作；页面入口、关键播放操作、保存、删除确认和需要解释的操作保留清楚文字。沿用 AppIcon，不加图标依赖。

## 视觉规范

### 色彩

深色主题是参考图的主基准，保留已有浅色主题并以同一层级映射：

| Token | 深色 | 浅色 | 用途 |
| --- | --- | --- | --- |
| `--bg-main` | `#171717` | `#FAFAF8` | 页面画布 |
| `--bg-sidebar-solid` | `#111111` | `#F0F0ED` | 主导航 |
| `--bg-elevated` | `#202020` | `#FFFFFF` | 浮层、输入和局部表面 |
| `--bg-active` | `#373737` | `#E5E5E2` | 当前项和选中项 |
| `--border-default` | `#303030` | `#DEDEDA` | 列表与区域分隔 |
| `--text-primary` | `#F1F1F1` | `#242424` | 标题和正文 |
| `--text-secondary` | `#A3A3A3` | `#6C6C6C` | 描述和次级操作 |
| `--accent` | `#E5E5E5` | `#262626` | 主操作、焦点和选中提示 |

错误、警告、成功状态沿用语义色，不把强调色扩散到普通导航和大面积背景。页面不使用渐变；静态内容不加投影，只有菜单、弹出层和浮动面板使用轻量投影。

### 字体与尺寸

- 正文使用系统无衬线字体：`Segoe UI Variable`、`Segoe UI`、`PingFang SC`、`Microsoft YaHei UI`。
- 页面主标题使用 Georgia 作拉丁标题显示，中文回退到系统中文衬线；正文、工具、数据保持无衬线。
- 页面标题 26–30px，区块标题 17–20px，正文 13–15px，辅助信息不小于 11px。
- 页面按 4/8px 间距组织；图标使用 16/18/20px；常规工具按钮 34–38px；常用输入 38px。
- 控件圆角 6–8px，弹层与主要面板 10px，海报沿用图片比例并用 6px 圆角。以分隔和对齐建立层级，不把所有内容切成同样大小的圆角卡片。

### 外壳与布局

桌面主外壳采用固定侧栏、顶部轻工具条和独立滚动内容区。侧栏默认约 248px，收起约 68px；窗口工具栏约 52px。宽屏内容左右内边距约 40px，窄桌面约 24px，手机沿用抽屉导航和安全区。

```text
┌侧栏 248px──────────┬窗口工具栏：导航／搜索／窗口操作────────┐
│ 工作区与功能入口    ├──────────────────────────────────────┤
│                     │ 页面标题、筛选、视图和主要操作         │
│ 当前项              │                                      │
│                     │ 海报墙／文件清单／详情／设置表单       │
│ 队列、设置          │                                      │
└─────────────────────┴──────────────────────────────────────┘
```

在线首页和媒体浏览保留宽幅海报墙及来源信息；电影/电视剧延续文件列表与右侧详情；Amane 保留页内顶栏、筛选与海报墙；设置使用左侧分组、右侧表单；播放器以画面为主，控件融入视频浮层。弹窗、抽屉、队列统一使用一致的头部、内容滚动区和底部操作区。

## 设计原则与自我校对

这套方向来自用户给出的 Claude 桌面端图：侧栏收纳入口，工作区保持连续，灰阶表面用选中态和细分隔建立层次，标题/正文的字形对比提供识别度。它针对影盒的多功能桌面工作流；媒体内容继续使用海报、列表和详情组合，不把聊天页或 Customize 列表硬套给其他页面。强调色只编码操作和状态。深浅主题共同维护同一对比和层级。

自检：视觉特征具体落在连续的深石墨工作区、单一侧栏、克制的选中底色、衬线页面标题与密集媒体内容上；不使用彩色渐变、大量装饰数字、通用仪表盘卡片或对话式布局。窄屏时侧栏变为抽屉，操作不依赖悬停，焦点和减少动态效果偏好保持可用。
