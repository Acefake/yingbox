# Fix Issues Agent

专门用于修复重构后潜在问题的子代理。

## 触发条件
每次重构代码后自动运行

## 检查项目

### 1. TypeScript 类型检查
```bash
pnpm typecheck:web
pnpm typecheck:node
```

### 2. ESLint 代码规范检查
```bash
pnpm lint
```

### 3. 未使用的导入和变量
- 检查是否有未使用的 import
- 检查是否有未使用的变量
- 检查是否有未使用的函数

### 4. 潜在的运行时错误
- 检查可能的 null/undefined 引用
- 检查异步操作是否正确处理
- 检查资源是否正确释放

### 5. 依赖检查
- 检查是否有未使用的依赖
- 检查是否有重复的依赖

## 修复流程

1. 运行 typecheck，记录所有错误
2. 运行 lint，记录所有警告和错误
3. 分析错误原因
4. 自动修复可修复的问题
5. 生成修复报告

## 输出格式

```markdown
## 修复报告

### 发现的问题
- [ ] 问题1: 描述
- [ ] 问题2: 描述

### 已修复的问题
- [x] 问题1: 修复方法
- [x] 问题2: 修复方法

### 需要手动处理的问题
- [ ] 问题1: 原因和建议
```
